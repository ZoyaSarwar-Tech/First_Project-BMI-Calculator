# 🧮 BMI Calculator (Python)

A simple Body Mass Index (BMI) Calculator built using Python.  
This project calculates a person's BMI based on height and weight and categorizes the result according to standard BMI classifications.

---

## 📌 Project Overview

The BMI Calculator is a beginner-friendly console application designed to:

- Take user input (height & weight)
- Perform mathematical calculations
- Apply conditional logic
- Display health category results

This project demonstrates basic Python programming concepts and real-world formula implementation.

---

## 🚀 Features

✔ User input handling  
✔ BMI calculation using formula  
✔ Automatic BMI category detection  
✔ Clear and readable output  
✔ Beginner-friendly structure  

---

## 🧠 BMI Formula Used
BMI = weight (kg) / (height (m))²


---

## 📊 BMI Categories

| BMI Range        | Category        |
|------------------|----------------|
| Below 18.5       | Underweight    |
| 18.5 – 24.9      | Normal Weight  |
| 25 – 29.9        | Overweight     |
| 30 and above     | Obese          |
